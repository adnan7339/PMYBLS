# 🔍 CNIC Search System

Live demo ko access karne ke liye Excel file (.xlsx) upload karein aur CNIC search karein.

## ✨ Features

- 📊 Excel (.xlsx/.xls) file upload
- 🔍 Fast CNIC search
- 📱 Responsive design
- ⚡ Client-side processing (no server required)
- 🎨 Modern UI with gradient design

## 🚀 Live Demo

[View Live Demo](https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/)

## 💻 Usage

1. Excel file upload karein
2. CNIC enter karein (format: XXXXX-XXXXXXX-X)
3. Search button click karein
4. Results dekhen

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- SheetJS (XLSX library)
